# Featured tours typography and design credits

- Roboto Condensed Bold (700), self-hosted WOFF2, instantiated from the official Google Fonts variable TTF: https://github.com/google/fonts/tree/main/ofl/robotocondensed. Includes Latin and Cyrillic glyphs; Korean uses system sans fallbacks. Distributed under the SIL Open Font License in `OFL.txt`.
- Supporting typography reuses the existing local Manrope assets and license in `../agents-atlas/`.
- Photography retains all ten existing local assets and their ordering. Original photo credits: `../../img/homepage/SOURCES.md`.
- Photo-frame composition inspired by [Aceternity's Apple Cards Carousel](https://ui.aceternity.com/components/apple-cards-carousel). Implemented with the application's existing Swiper; no Aceternity code or additional dependency was imported.
- `expedition-lines.svg` is original static sunrise/landscape line artwork. Following user feedback, the initial butter-yellow band was replaced with warm ivory and restrained gold artwork; destination imagery retains natural colors.
